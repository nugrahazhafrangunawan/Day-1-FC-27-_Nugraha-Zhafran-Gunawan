## Rangkuman dokumentasi kegiatan workshop (Day1)

**A. Materi Pokok: From AI to GitHub**

Pemateri: Nugi Farhan (Senior Product Designer). Capaian sesi: memahami prompt yang spesifik, mengenali repository, commit, branch, dan pull request, membedakan Git dan GitHub, serta melakukan version control.

**Prompt Engineering**

Prompt adalah instruksi yang diberikan ke AI (pertanyaan, kata kunci, instruksi rumit, atau kode). Prompt engineering adalah cara merancang instruksi agar jawaban tepat, relevan, dan layak dipakai.
Konteks sangat menentukan: prompt singkat tanpa konteks menghasilkan jawaban umum, sedangkan prompt dengan konteks menghasilkan jawaban yang sesuai kebutuhan.
Struktur prompt yang baik: Role (peran AI), Task (tugas utama), Context (kebutuhan dan batasan), dan Format (bentuk keluaran).
Taktik: pakai kata kerja aksi, tentukan panjang dan format output, sebutkan target audiens, sertakan fakta dan data, rujuk dokumen tertentu, dan definisikan istilah kunci.
Keuntungan: performa model meningkat, bias dan respons offensive berkurang, hasil lebih terkontrol, dan pengalaman pengguna lebih baik.

**Git dan GitHub**

Git adalah version control system yang melacak siapa, kapan, dan apa yang berubah pada file. Dibuat Linus Torvalds tahun 2005 dan bekerja secara lokal.
GitHub adalah platform web untuk menyimpan repository Git secara online dan berkolaborasi.
Tiga area Git: working directory (salinan proyek yang dikerjakan), staging area (menampung perubahan untuk commit berikutnya), dan repository/.git directory (menyimpan metadata dan database proyek).
Alur kerja: ubah file, git add ke staging area, git commit ke repository, lalu git push ke GitHub.

Struktur jurusan: dipimpin Ketua Jurusan (dibantu Sekretaris dan Admin), dengan empat prodi (TI, TMJ, TMD, RKS), Lab Komputer dan Jaringan, Lab Cyber Security, dan beberapa Kelompok Bidang Keahlian.

Lima agenda: penguatan internal, kerja sama industri, pengembangan SDM, sarana prasarana, dan inkubator bisnis. Mitra antara lain Cisco, Huawei, Oracle, dan Agate.

Kurikulum TMD 2026: berbasis OBE, 55 mata kuliah dengan 144 SKS dalam 8 semester, berfokus pada game, animasi, dan multimedia interaktif. Ada magang industri 12 SKS di semester 7 dan skripsi di semester 8.

MBKM dan MSIB: belajar di luar prodi lewat 8 bentuk kegiatan (pertukaran pelajar, magang, asistensi mengajar, riset, proyek kemanusiaan, wirausaha, proyek independen, KKN). MSIB berdurasi 1 semester, bersertifikat, dan dikonversi 20 SKS.

Layanan lab: peminjaman alat yang dipakai di lab (hubungi teknisi dan tinggalkan KTM sebagai jaminan) atau dibawa pulang (isi form bertanda tangan Kalab). Peminjaman ruangan: konfirmasi ke teknisi/admin, cek jadwal, ajukan ke Kalab, tunggu ACC, lalu konfirmasi slot.

Tata tertib: pelanggaran ditangani bertahap (teguran dosen, lapor ke KPS, pembinaan, panggil orang tua/wali, pemantauan, lalu sanksi). Aturan penting: rambut putra pendek dan rapi, berpakaian rapi dengan sepatu tertutup belakang, dilarang makan, minum, dan merokok di kelas dan lab, serta dilarang berbuat curang, berjudi, dan berkelahi.
